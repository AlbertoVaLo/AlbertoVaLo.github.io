Política de privacidad de Tiko

Tiko es una aplicación personal de escritorio. Accede en solo lectura a Gmail y Google Calendar de las cuentas que el propio usuario conecta, únicamente para elaborar su resumen diario.

Los datos se procesan en el ordenador del usuario y no se almacenan en servidores del desarrollador. Para redactar el resumen, extractos de correos y eventos pueden enviarse al proveedor de IA que el usuario configure (la API de Gemini de Google, o un modelo local con Ollama que no envía nada fuera del equipo). Los datos no se venden ni se usan para publicidad. Los tokens se guardan cifrados en el equipo y el usuario puede revocarlos desde su cuenta de Google.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
